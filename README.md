## 🚀 Featured Project

### 🩺 [Type 2 Diabetes Risk Prediction — MSc Machine Learning Project](https://github.com/KiruiBK/type2-diabetes-risk-prediction)

A machine-learning research project investigating approaches to Type 2 diabetes risk screening using the CDC Diabetes Health Indicators dataset.

**What I worked on:**
- Developed and evaluated Logistic Regression, Random Forest and XGBoost models.
- Applied SMOTE and cross-validation to address class imbalance and support model evaluation.
- Experimented with model stacking and a two-stage prediction cascade.
- Used SHAP to investigate feature contributions to model predictions.
- Documented model performance, methodological limitations and opportunities for improvement.

**Technologies:** Python, pandas, NumPy, scikit-learn, XGBoost, imbalanced-learn, SHAP and Matplotlib.

[Explore the project and source code →](https://github.com/KiruiBK/type2-diabetes-risk-prediction)
